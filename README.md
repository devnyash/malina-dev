# Автотехцентр «Малина»

Статический сайт без npm, сборщика и сторонних JavaScript-библиотек.

## Как открыть

Для проверки поведения через локальный веб-сервер выполните:

```bash
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>.

## Структура

- `index.html` — главная страница вместе с JavaScript;
- `privacy/index.html` — политика обработки персональных данных по адресу `/privacy/`;
- `consent/index.html` — согласие на обработку персональных данных по адресу `/consent/`;
- `assets/site-v2.css` — стили главной страницы и карты;
- `assets/legal.css` — стили юридических страниц;
- `assets/legal.js` — индикатор чтения юридических документов;
- `assets/` — логотипы, иконка сайта и фотографии;
- `Caddyfile` — чистые URL и постоянные редиректы со старых `.html` адресов;
- `robots.txt` и `sitemap.xml` — файлы для поисковых систем.

Главная страница находится по адресу `/`, юридические документы — по адресам
`/privacy/` и `/consent/`. Для редиректов `/index.html` → `/`,
`/privacy.html` → `/privacy/` и `/consent.html` → `/consent/` сервер должен
использовать правила из `Caddyfile`.

Кнопка MAX открывает личный контакт: <https://web.max.ru/17121427>.

Кнопки записи открывают внешний виджет «АвтоДилер Онлайн». Для его работы браузер
должен разрешать загрузку скрипта `https://online.autodealer.ru/widget/app.js`.

Интерактивная карта в блоке контактов работает через JavaScript API Яндекс Карт
2.1. Если API недоступен или заблокирован настройками приватности, вместо пустого
блока показывается адрес и кнопка перехода в Яндекс Карты.

В Кабинете разработчика Яндекса добавьте рабочий домен сайта в ограничения
API-ключа. Для проверки на другом домене его также нужно временно разрешить в
настройках ключа.
