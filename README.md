# Автотехцентр «Малина»

Статический сайт автотехцентра: без npm, сборки и JavaScript-фреймворков.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Юридические страницы находятся по адресам
`/privacy/` и `/consent/`.

## Структура проекта

- `index.html` — главная страница, SEO-разметка и её JavaScript;
- `privacy/index.html` — политика обработки персональных данных;
- `consent/index.html` — согласие на обработку персональных данных;
- `assets/main.css` — общие стили и оформление главной страницы;
- `assets/legal-pages.css` — дополнительные стили юридических страниц;
- `assets/legal.js` — индикатор прокрутки юридических документов;
- `assets/images/` — фотографии для блоков главной страницы;
- `assets/logo-malina.svg`, `assets/logo-malina-light.svg` — варианты логотипа;
- `assets/favicon.svg` — иконка вкладки браузера;
- `assets/max.svg` — иконка ссылки на MAX;
- `Caddyfile` — настройки веб-сервера и редиректы на чистые URL;
- `robots.txt`, `sitemap.xml` — инструкции и карта сайта для поисковиков;
- `START-HERE.md` — короткая памятка по локальному запуску;
- `.gitignore` — файлы, которые Git не должен отслеживать.

## Внешние сервисы

На главной используются Яндекс Метрика, карта Яндекса и виджет онлайн-записи
«АвтоДилер». Поэтому для их работы нужен доступ к интернету. Кнопка MAX ведёт
на контакт автотехцентра.

Для публикации с редиректами используйте `Caddyfile`. Обычный локальный сервер
Python подходит для просмотра страниц, но правила редиректов не применяет.
