# Как запустить сайт

Устанавливать Node.js и npm не нужно.

Открой терминал в папке проекта и запусти:

```bash
python3 -m http.server 8000
```

Затем открой <http://localhost:8000>.

Юридические страницы доступны по адресам <http://localhost:8000/privacy/> и
<http://localhost:8000/consent/>.

## Где менять сайт

- `index.html` — тексты, разметка и интерактивность.
- `assets/main.css` — общие стили и оформление главной страницы.
- `assets/legal-pages.css` — дополнительное оформление юридических страниц.
- `assets/images/` — фотографии.

После изменения файла нажми Ctrl+S и обнови страницу в браузере.
